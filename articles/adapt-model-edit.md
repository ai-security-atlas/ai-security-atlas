Targeted model editing modifies a small set of learned associations inside a trained model without retraining it from scratch. The goal is a precise change, for example updating a specific factual association, while leaving unrelated behavior intact. Work such as *Locating and Editing Factual Associations in GPT* frames the problem as locating where an association is stored and then writing a controlled update to those parameters.

The method operates directly on a model's [weights, parameters and activations](../nodes/concept-parameters.md), which it requires as the substrate for any edit. A recurring concern is locality: an edit intended to be narrow can produce side effects on related knowledge, so success has to be evaluated rather than assumed.

Targeted editing underpins [machine unlearning and concept erasure](../nodes/adapt-unlearning.md), which applies edit-style interventions to remove influence or concepts. It is also relevant to security because it can be used by [unauthorized factual model editing](../nodes/attack-factual-edit.md), where the edit inserts false or attacker-chosen associations. The technique itself is neutral; its acceptability depends on authorization and on whether the edit's locality and side effects have been measured. Specific editing algorithms and their reliability are left to the cited source.
