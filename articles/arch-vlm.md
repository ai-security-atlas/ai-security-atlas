Vision-language models (VLMs) jointly process visual and textual input, coupling a visual representation with language processing so a single model can reason over images and text together. Built on [Transformers](../nodes/arch-transformer.md), a typical VLM encodes an image into representations that are fused with token embeddings and consumed by a language model. The defining structural feature is that there are multiple input pathways: content can enter through text and through the visual channel, and both influence the model's output.

## Why it matters for security analysis

That additional visual pathway is the crux of the changed threat surface. Because instructions or adversarial signals can be carried in an image rather than only in text, the atlas marks [instructions carried through multimodal content](../nodes/attack-multimodal-injection.md) and [optimized visual jailbreaks](../nodes/attack-visual-jailbreak.md) as relevant to this scope — the first concerning directives embedded in images or other media, the second concerning image perturbations optimized to steer behavior. These indicate applicability, not demonstrated weakness in any specific model. Analysis should account for both channels and for how visual inputs are trusted relative to text. Concerns tied purely to text-only decoding still matter but do not capture the multimodal surface. Empirical specifics and attack conditions are deferred to the cited literature.
