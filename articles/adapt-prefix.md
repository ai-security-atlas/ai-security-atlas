Prefix tuning adapts a model by learning a set of continuous vectors, a "prefix," that is prepended to the input at each layer while the base model's own parameters stay frozen. These learned prefixes are not words but trainable activations that condition the frozen network toward a target task. Because only the prefix is optimized, the approach is lightweight and lets one base model serve many tasks by swapping prefixes. The method is introduced in *Prefix-Tuning: Optimizing Continuous Prompts for Generation*.

Prefix tuning is a form of [parameter-efficient fine-tuning](../nodes/adapt-peft.md), which it requires as its conceptual basis: adapt a small added set of parameters rather than the full model. It sits alongside related PEFT techniques that also avoid touching the base weights, differing mainly in where and how the learned parameters are injected.

Within this dataset the technique is presented as neutral and carries no direct link to a specific attack. Its typical uses are efficient task specialization and controllable generation where retraining the whole model would be costly. Details of how the prefix is parameterized across layers, and how its length affects capacity, are left to the cited source.
