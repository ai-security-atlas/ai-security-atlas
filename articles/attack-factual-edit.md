Unauthorized factual model editing modifies selected internal associations so that the model returns attacker-chosen answers to later queries. It routes toward [establishing persistent attacker influence](../nodes/goal-persistence.md) and [manipulating outputs, predictions or decisions](../nodes/goal-decisions.md), because the change is written into the model's parameters rather than supplied at inference time.

Conceptually the technique applies [targeted model editing](../nodes/adapt-model-edit.md) — methods that locate and rewrite specific factual associations in a [language model](../nodes/arch-decoder.md) — to alter a chosen fact while leaving unrelated behavior largely intact. The attacker-controlled input is the edit specification (which association to change and to what); the victim-controlled state is the model whose weights are modified and every downstream user who queries it afterward. A defining caveat is that targeted-editing research is itself neutral; the threat arises only when such an edit is applied without authorization, which requires its own access and authorization context to be established.

This sits in the representation-and-weight-interventions family alongside merge- and conversion-based tampering, which introduce untrusted changes through different artifact operations.

The atlas lists no dedicated mitigation node for this entry; the mechanism points toward provenance, change control over weights, and regression testing of factual behavior. Evaluation is framed through [attack success and severity](../nodes/eval-asr.md) under an [explicit threat model](../nodes/eval-threat-model.md). For the specific editing method and its demonstrated precision and side effects, defer to the cited source.
