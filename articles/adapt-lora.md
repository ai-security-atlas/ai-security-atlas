LoRA (low-rank adaptation) is a parameter-efficient way to fine-tune a large model. Instead of updating the full weight matrices, it freezes the base model and learns small low-rank update matrices that are added to selected layers. Because these updates have far fewer parameters than the originals, training and storage costs drop sharply, and the resulting adapter can be shipped separately from the base weights. The method is introduced in *LoRA: Low-Rank Adaptation of Large Language Models*.

LoRA is a form of [parameter-efficient fine-tuning](../nodes/adapt-peft.md), which it requires as its conceptual foundation: adapt an added, small set of parameters rather than the whole network. Its portability is a practical strength, since a single base model can host many task-specific adapters.

That same portability is why the technique is relevant to security. It can be used by [malicious adapters or adapter substitution](../nodes/attack-adapter-tamper.md), where an adapter is tampered with or swapped to change behavior, so provenance and integrity of adapter files matter. LoRA is also a building block of [QLoRA](../nodes/adapt-qlora.md), which pairs it with quantized base weights. Whether a LoRA update is benign depends on its training data, objective and deployment, not on the method itself.
