Textual inversion is a personalization technique for generative image models that learns a new embedding to represent a concept, such as a specific object or style, from a handful of example images. The learned embedding is tied to a placeholder token so the concept can then be summoned in prompts and composed with the model's existing capabilities. The base model is not retrained; only the new concept embedding is optimized. The method is introduced in *An Image is Worth One Word: Personalizing Text-to-Image Generation using Textual Inversion*.

The technique requires a [diffusion generative model](../nodes/arch-diffusion.md) and operates in the space of [input and output embeddings](../nodes/concept-embeddings.md), where the learned concept vector resides.

A naming caution is worth stressing: textual inversion is distinct from [model inversion and attribute inference](../nodes/attack-attribute.md), a privacy attack that reconstructs training data or attributes from a model. Despite the shared word "inversion," they are unrelated concepts. Textual inversion is a neutral personalization method whose typical uses are creative and reproducible generation of user-specified concepts. How many example images suffice and how the embedding is optimized are left to the cited source.
