In a transformer, the *residual stream* is the shared representation that runs through the network's depth. Each block does not replace this representation; it reads from it and *adds* its contribution back, so information accumulates along a common pathway from input to output. This block structure — attention and feed-forward sublayers repeatedly writing into the same stream — is what lets later layers build on earlier ones. The concept builds on [transformers](../nodes/arch-transformer.md) and on [weights, parameters and activations](../nodes/concept-parameters.md), since the stream itself is carried by activations that the blocks' weights transform.

Why single this out: because the residual stream is a shared, additive channel, specific directions or components within it can correspond to identifiable features, and reading or perturbing the stream at a chosen layer offers a handle for *localized* interventions — targeting one place in the computation rather than the whole model.

That handle is what the dependent techniques exploit. This concept is a prerequisite for [activation steering](../nodes/adapt-steering.md), which nudges the stream at inference time to shift behavior, and for [refusal-direction ablation / abliteration](../nodes/adapt-abliteration.md), which acts on a particular direction associated with a behavior. The concept itself is neutral structure; whether a given direction carries a given behavior, and how reliably, is an empirical claim for the cited sources.
