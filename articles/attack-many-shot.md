Many-shot context attacks use long sequences of demonstrations, packed into a large context window, to steer a model toward behavior it would otherwise decline. It is a [variant of jailbreaking and refusal bypass](../nodes/attack-jailbreak.md) and routes toward [violating intended behavioral constraints](../nodes/goal-behavior.md).

Conceptually the technique leans on [context windows and in-context learning](../nodes/concept-context.md): by filling the context with many examples that model the target behavior, the attacker biases the model's continuation toward that pattern. The attacker-controlled input is the assembled sequence of demonstrations; the victim-controlled state is the [language model](../nodes/arch-decoder.md) and its trained refusals, which the accumulated in-context evidence competes against. What distinguishes it from other jailbreak variants is scale — it exploits long-context capacity specifically, rather than a single crafted instruction or a gradient-optimized suffix.

A learner should treat the result as setting-dependent: context capacity, sampling parameters, and the exact target version all materially affect whether the technique works, so an outcome on one configuration does not transfer automatically.

The atlas lists no dedicated mitigation node on this entry; refusal robustness under long contexts and input review are the natural references. Evaluation is framed through [attack success and severity](../nodes/eval-asr.md), an [explicit threat model](../nodes/eval-threat-model.md), and the [HarmBench benchmark](../nodes/eval-harmbench.md). This attack belongs to the prompt-and-context-manipulation family. For how effectiveness scales with the number of demonstrations and on which models, defer to the cited source.
