The AgentDojo benchmark is a source-specific reference for evaluating agent tasks together with prompt-injection attacks and defenses in a dynamic environment. Rather than scoring isolated prompts, it exercises an agent as it plans, calls tools, and consumes tool output, so both task completion and susceptibility to injected instructions can be observed in the same setting.

## What it evaluates

It is used to study agent- and tool-centric attacks such as [agent or connector confused-deputy abuse](../nodes/attack-confused-deputy.md), [exploitation of excessive delegated agency](../nodes/attack-excessive-agency.md), [improper handling of model-generated output](../nodes/attack-output-sink.md), [inter-agent trust and message manipulation](../nodes/attack-multiagent.md), [persistent agent-memory poisoning](../nodes/attack-memory-poison.md), [tool definition or behavior changes after approval](../nodes/attack-tool-rugpull.md), [tool-description poisoning](../nodes/attack-tool-description.md), and [tool-output injection](../nodes/attack-tool-output.md).

Because it pairs utility with attacks, it is well suited to exposing defenses that block injections at the cost of breaking normal task performance. Its coverage is nonetheless scope-limited: results reflect the tasks, tools, and injection patterns implemented in the environment. A high score is not proof that an agent resists every prompt injection or that a deployed system is safe, and the benchmark's fixed scenarios may not represent an adaptive attacker. Defer to the cited source for the environment's exact task suite, threat assumptions, and reported outcomes.
