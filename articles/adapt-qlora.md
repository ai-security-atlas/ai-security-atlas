QLoRA is a fine-tuning approach that combines quantized base weights with low-rank adaptation. The large base model is held in a reduced numerical precision to shrink its memory footprint, and a small trainable [LoRA](../nodes/adapt-lora.md) adapter is learned on top while the quantized base stays frozen. This lets sizable models be fine-tuned on more modest hardware. The method is described in *QLoRA: Efficient Finetuning of Quantized LLMs*.

The technique requires and uses two building blocks: [LoRA](../nodes/adapt-lora.md) for the low-rank update and [quantization and numerical precision](../nodes/transform-quantization.md) for the compressed base weights. Specifically, QLoRA stores frozen base parameters in 4-bit NormalFloat (NF4) precision with double quantization of the quantization scales, dequantizes blocks to 16-bit precision during the forward and backward passes so gradients flow only into the higher-precision adapter matrices, and uses paged optimizers to manage memory spikes.

As its summary notes, QLoRA is neither a model format nor an attack. It is a training-time efficiency method, distinct from serialization formats that merely store weights and distinct from the quantization step it relies on. Within this dataset it carries no direct link to a specific attack, and whether a resulting adapter is benign depends on the data, objective and deployment. The precise quantization scheme and the accuracy retained under it are left to the cited source.
