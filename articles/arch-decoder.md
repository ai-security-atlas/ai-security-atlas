Decoder-only autoregressive language models generate token sequences one step at a time, each token conditioned on the preceding context. Built on [Transformers](../nodes/arch-transformer.md), they use causal (masked) attention so predictions depend only on earlier positions. A practical distinction the atlas emphasizes is between base checkpoints, trained purely to continue text, and instruction-tuned checkpoints aligned to follow directions, since the two differ in behavior and in what a given technique targets. These models sit upstream of [context windows and in-context learning](../nodes/concept-context.md), [retrieval-augmented generation](../nodes/system-rag.md), and [tool-using agents](../nodes/system-agent.md).

## Why it matters for security analysis

Autoregressive generation and the reliance on in-context conditioning define much of this scope. Relevant techniques span the input surface — [direct prompt injection](../nodes/attack-direct-injection.md), [jailbreaking and refusal bypass](../nodes/attack-jailbreak.md), [many-shot context attacks](../nodes/attack-many-shot.md), [gradient-guided adversarial suffixes](../nodes/attack-gcg.md), and [transfer of adversarial prompts](../nodes/attack-transfer-prompts.md) — as well as training and adaptation, including [instruction-tuning data poisoning](../nodes/attack-sft-poison.md), [preference or reward-signal manipulation](../nodes/attack-preference-poison.md), [persistent conditional LLM backdoors](../nodes/attack-sleeper.md), and [malicious adapters or adapter substitution](../nodes/attack-adapter-tamper.md). Confidentiality concerns such as [language-model training-data extraction](../nodes/attack-training-extraction.md), [system or developer prompt disclosure](../nodes/attack-prompt-leak.md), and [partial parameter recovery from API behavior](../nodes/attack-projection-theft.md) also apply. These indicate applicability, not proven weakness; specifics rest with the cited sources.
