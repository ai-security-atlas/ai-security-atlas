Soft prompt tuning adapts a model by learning prompt embeddings directly, rather than by authoring ordinary discrete text prompts. A set of continuous vectors is optimized and prepended to the input embeddings while the base model's weights remain frozen, so the learned "prompt" is a trainable point in embedding space instead of a sequence of words. The method is described in *The Power of Scale for Parameter-Efficient Prompt Tuning*.

The technique requires [input and output embeddings](../nodes/concept-embeddings.md), the space in which the learned prompt lives, and is a form of [parameter-efficient fine-tuning](../nodes/adapt-peft.md), since only the small prompt is trained. This distinguishes it from ordinary prompting, where a human writes discrete tokens, and from methods that update the model body: here the adaptation is a compact learned embedding.

Within this dataset the technique is presented as neutral and carries no direct link to a specific attack. Its typical uses are efficient task specialization and conditioning a shared frozen model for many downstream tasks. How the number of soft-prompt vectors trades off against capacity, and how performance scales with model size, are left to the cited source.
