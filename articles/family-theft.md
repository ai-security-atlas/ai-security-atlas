This family groups techniques that acquire a model's artifacts or reproduce its behavior, distinguished mainly by threat model and by what the attacker walks away with. The shared objective is *Appropriate model artifacts or capabilities*, whether that means the actual parameters or a functional copy that behaves like the target.

Members span a spectrum of access. [Unauthorized checkpoint or adapter theft](../nodes/attack-weight-theft.md) takes the literal weight files. [Black-box functional model extraction](../nodes/attack-model-imitation.md) and [Unauthorized teacher-student capability transfer](../nodes/attack-distillation-theft.md) instead reconstruct behavior by querying a target and training a substitute. [Partial parameter recovery from API behavior](../nodes/attack-projection-theft.md) sits between them, recovering some parameters from observable outputs.

The atlas explicitly separates weight theft from functional extraction: one is exfiltration of stored artifacts, the other is behavioral reproduction that may never touch the original files. That distinction matters because the two can imply different defenses—access control and artifact integrity versus query monitoring and rate limiting. Use this grouping to navigate intellectual-property and confidentiality threats to the model itself, keeping in mind that "stealing a model" may mean copying its files or merely cloning what it does.
