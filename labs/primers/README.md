# Primers

The labs assume you know appsec, Docker, Python and HTTP. They do not assume you know machine learning or statistics. These six short reference pages define the ML and statistics terms the labs use, each under its own heading, so a lab can link straight to the definition. Read one when a lab points you to it, or skim them all before a workshop.

| Primer | What it covers |
| :--- | :--- |
| [Reading the numbers](reading-the-numbers.md) | Rates, brackets (Wilson and Newcombe intervals), percentage points, release gates, kappa, TPR, FPR, AUC, p-values, z-scores and permutation tests. |
| [ML in one page](ml-in-one-page.md) | Weights, logits, softmax, loss, gradients, the training loop (batch, epoch, learning rate, optimizer), overfitting, fine-tuning and LoRA. |
| [Sampling knobs](sampling-knobs.md) | Greedy decoding, temperature, seed, top-k, top-p, end-of-turn token and max tokens, and why temperature 0 trials are not independent. |
| [Vectors without the math](vectors-without-the-math.md) | Vectors, norms, cosine similarity, embeddings, rank, SVD, singular values, projection and least squares. |
| [Inside a transformer block](inside-a-transformer-block.md) | Tokens, embeddings, RoPE, attention (query, key, value), heads, GQA, MLP, residual stream, RMSNorm, KV cache, prefill and decode, encoders and decoders. |
| [Diffusion in one paragraph](diffusion-in-one-paragraph.md) | Noise, the U-Net denoiser, schedulers and steps, DDPM and DDIM, latents, the text encoder and the guidance scale. |
