# Refunds and credits

## Refund limits
Support agents may refund up to $500 per order without manager approval. This limit does not apply to orders paid by invoice: those always need sign-off from finance first.

## How the money goes back
Refunds go back to the original payment method. Card refunds appear on the customer's statement within five working days. Store credit is offered only when the customer asks for it.

## Partial refunds
A partial refund is right when one item of a bundle is faulty. Refund the list price of that item, never the bundle discount. Note the item code in the ticket.
